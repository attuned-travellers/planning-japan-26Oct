# planning-japan-26Oct

Trip planning for **Japan, October 2026** by **Attuned Travellers**.

## Overview

A working repository for the October 2026 Japan trip — the overall route,
day-by-day schedule, bookings, budget and checklists. City-level notes and
place cards live in their own repositories:

- [japan-osaka](https://github.com/attuned-travellers/japan-osaka) — Osaka (大阪)
- [japan-kyoto](https://github.com/attuned-travellers/japan-kyoto) — Kyoto (京都)

## Structure

```
.
├── itinerary/     # route overview and day-by-day plan
├── bookings/      # flights, stays, rail, reservations
├── budget/        # costs and expenses
└── checklists/    # packing, documents, pre-departure
```

Directories are added as content grows.
